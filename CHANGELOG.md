# Changelog

Все заметные изменения проекта ForumReader.

## [3.0.0] — 2026-11-18

### Изменено
- Все статьи переписаны и расширены: структура «Что важно / Как действовать / Итоги», у длинных статей добавлен «Разбор примера».
- Количество тем доведено до **250**; заголовки уникальны и подобраны под подкатегорию.
- Светлая тема заменена на **бежевую** (тёплые поверхности, текст и акценты); тёмная тема без изменений.

### Добавлено
- Воспроизводимый генератор статей с фиксированным seed: темы, авторы, теги, даты и ответы распределяются по каналам случайно, но стабильно.
- В комплекте 250 статей в 15 каналах (8 категорий): минимум 500 символов (фактический минимум — 954), каждая седьмая превышает 1500 символов.
- `index.html` разделён на три файла: `index.html`, `styles.css`, `app.js`.
- Миграция `forumreader_seed_v6`: заменяет только демонстрационные темы, сохраняя созданные пользователем темы, каналы и категории.

## [2.2.0] — 2026-11-18

### Добавлено
- Ещё 35 тематических статей: итого **40 новых** (вместе с партией 2.1.0) и 45 тем в примере по умолчанию.
- Статьи распределяются случайно по каналам внутри своих тематических групп (воспроизводимый генератор с фиксированным seed); ключ миграции обновлён до `forumreader_seed_v3`.

## [2.1.0] — 2026-11-18

### Добавлено
- Пять новых статей, случайно распределённых по каналам: Математика, Физика, Общие темы, Консоли, Фриланс.
- Статьи добавляются один раз даже в уже сохранённые данные (ключ `forumreader_seed_v2`); после «Сбросить к примеру» возвращаются вместе с примером.

## [2.0.0] — 2025-01-01

### Добавлено
- Фильтр тем по тегам («Все», «Вопрос», «Инструкция», «Обсуждение», «Анонс») с подсчётом количества.
- Удаление темы и отдельных ответов с подтверждением в модальном окне.
- Запоминание имени автора между сессиями (ключ `forumreader_author`).
- Оценка времени чтения темы и подсказка с полной датой при наведении на относительное время.
- Кнопка «свернуть / развернуть» для всех категорий сразу.
- Подпись с размером локального хранилища в сайдбаре.
- Skip-link «К содержимому» и корректные `aria-label` / `aria-expanded` / `role` у интерактивных элементов.

### Изменено
- Расширенный Markdown в темах и ответах: заголовки `##` и `###`, нумерованные списки, цитаты `>`, ссылки, `инлайн-код`, `**жирный**`, `*курсив*`.
- Переработана типографика, сетка, тени и состояния наведения; единая шкала отступов.
- Карточки тем стали кликабельными с клавиатуры (`Enter`), добавлены чипы локации в результатах поиска.
- Мобильное меню закрывается по клику на затемнение и по кнопке в шапке панели.
- Тосты получили `role="status"` и корректно растягиваются на узких экранах.

### Исправлено
- Ответы, отправленные по `Ctrl/⌘ + Enter`, больше не отправляются дважды.
- Горячие клавиши не срабатывают, пока открыто модальное окно.
- `Escape` корректно очищает поиск, закрывает тему, модалку или меню — по приоритету.
- Дубликаты и пустые значения в данных нормализуются при загрузке.

### Совместимость
- Ключ хранения `mini_forum_v1` не изменился: существующие темы, каналы и категории сохраняются.
- Формат экспорта/импорта JSON остался прежним.
