# Changelog

Все заметные изменения проекта ForumReader.

## [2.0.0] — 2025-01-01

### Добавлено
- Фильтр тем по тегам («Все», «Вопрос», «Инструкция», «Обсуждение», «Анонс») с подсчётом количества.
- Удаление темы и отдельных ответов с подтверждением в модальном окне.
- Запоминание имени автора между сессиями (ключ `forumreader_author`).
- Оценка времени чтения темы и подсказка с полной датой при наведении на относительное время.
- Кнопка «свернуть / развернуть» для всех категорий сразу.
- Подпись с размером локального хранилища в сайдбаре.
- Skip-link «К содержимому» и корректные `aria-label` / `aria-expanded` / `role` у интерактивных элементов.

### Изменено
- Расширенный Markdown в темах и ответах: заголовки `##` и `###`, нумерованные списки, цитаты `>`, ссылки, `инлайн-код`, `**жирный**`, `*курсив*`.
- Переработана типографика, сетка, тени и состояния наведения; единая шкала отступов.
- Карточки тем стали кликабельными с клавиатуры (`Enter`), добавлены чипы локации в результатах поиска.
- Мобильное меню закрывается по клику на затемнение и по кнопке в шапке панели.
- Тосты получили `role="status"` и корректно растягиваются на узких экранах.

### Исправлено
- Ответы, отправленные по `Ctrl/⌘ + Enter`, больше не отправляются дважды.
- Горячие клавиши не срабатывают, пока открыто модальное окно.
- `Escape` корректно очищает поиск, закрывает тему, модалку или меню — по приоритету.
- Дубликаты и пустые значения в данных нормализуются при загрузке.

### Совместимость
- Ключ хранения `mini_forum_v1` не изменился: существующие темы, каналы и категории сохраняются.
- Формат экспорта/импорта JSON остался прежним.
